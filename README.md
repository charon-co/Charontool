# CharonTool

A modern, high-performance desktop application for managing Steam game installations, manifests, cloud saves, achievements, and integration utilities.

**Official Discord:** https://discord.gg/charon

---

### Tools & Runtimes
* **[DepotDownloaderMod](https://github.com/GogoVang/DepotDownloaderMod)** by [GogoVang](https://github.com/GogoVang) & [SteamAutoCracks](https://github.com/SteamAutoCracks) (based on [DepotDownloader](https://github.com/SteamRE/DepotDownloader)) — Steam depot downloader with custom manifest and key support.
* **[OpenSteamTool](https://github.com/OpenSteam001/OpenSteamTool)** by [OpenSteam001](https://github.com/OpenSteam001) — Steam manifest and DLC unlocker runtime.
* **[BetterSteamTools](https://github.com/madoiscool/BetterSteamTools)** by [madoiscool](https://github.com/madoiscool) — Enhanced OpenSteamTool fork with Lua script and config plugin support.
* **[Steamless](https://github.com/atom0s/Steamless)** by [atom0s](https://github.com/atom0s) — SteamStub DRM unpacker and remover.
* **[SmokeAPI](https://github.com/acidicoala/SmokeAPI)** by [acidicoala](https://github.com/acidicoala) — Steam API emulator and DLC unlocker proxy.
* **[SteamAutoCrack](https://github.com/SteamAutoCrack/SteamAutoCrack)** — Automated Steam game cracking and emulator packaging tool.

* **[Steam Achievement Manager (SAM)](https://github.com/gibbed/SteamAchievementManager)** by [Rick (gibbed)](https://github.com/gibbed) — Steam achievement management library (`SAM.API.dll`).

### Services & Providers
